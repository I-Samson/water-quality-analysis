# Water Quality Data Analysis

A data analysis and visualization project using the Water Potability dataset.

## Overview
Analyzed 3,276 water samples to explore factors affecting water safety.

## Tools Used
- Python, Pandas, Matplotlib, Seaborn
- Google Colab

## Key Findings
- Only ~39% of samples are classified as safe
- pH, Hardness, and Chloramines are key parameters
- No single feature alone determines potability

## Dataset
Kaggle - Water Potability by Aditya Kadiwal
